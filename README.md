# バベルTD

神に抗いながら無限に塔を伸ばしていく、縦画面タワーディフェンス。
TypeScript + Phaser 3 + Vite で作っています（ブラウザで動作、Webアプリとしてインストール予定）。

## 動かし方

```bash
npm install      # 初回のみ
npm run dev      # 開発サーバー起動 → http://localhost:5180
```

- スマホで試す: 同じWi-Fiにつないで、起動時に表示される `Network:` のURLを開く
- 調整用のデバッグ表示: URLの末尾に `?debug` を付ける（例: `http://localhost:5180/?debug`）
  - `1` / `2` / `3` … ゲーム速度 ×1 / ×3 / ×10
  - `P` … ポイント +500
  - `F` … 塔を1階伸ばす
  - `H` … 天才 +1
  - `G` … 神の妨害（ランダム） / `Z` 雷 / `X` 言語 / `C` 数値 / `V` 作業停止 / `B` 技術封印
- テスト: `npm test`
- 型チェック: `npm run typecheck`
- バランス計測（自動プレイのbotで何階・何分まで行けるか）: `npm run balance`
  - 数値を一時的に変えて試す: `OVERRIDE="ENEMY_SCALING.HP_MUL_PER_FLOOR=1.04" npm run balance`
  - 経過と死因も見る: `TRACE=1 npm run balance`
- 公開用ビルド: `npm run build`（`dist/` に出力。`npm run preview` で確認）
- アイコン画像の作り直し: `npm run icons`

## GitHub Pages で公開

`main` ブランチに push すると、GitHub Actions（`.github/workflows/deploy.yml`）が自動でビルドして公開する。
テストが失敗したときは公開されない。

- 初回だけ: リポジトリの **Settings → Pages → Build and deployment → Source** を「**GitHub Actions**」にする
  （「Deploy from a branch」のままだとビルド前のソースが公開され、画面が真っ黒になる）
- 公開URL: https://rewaita.github.io/babelTD/
- 進行状況はリポジトリの Actions タブで確認できる

## Webアプリとしてインストール（PWA）

`npm run build` した `dist/` をWebサーバー（HTTPS）に置くと、ホーム画面に追加できる。一度開けばオフラインでも遊べる。

- iPhone: Safariで開く → 共有 → 「ホーム画面に追加」
- Android / PC の Chrome: アドレスバーのインストールボタン、またはメニュー →「アプリをインストール」
- オフライン用の保存は2回目に開いたときから完全になる（1回目は読み込みながら保存するため）

## 操作

| 操作 | 内容 |
|---|---|
| 下部のカードをタップ | そのトラップを選ぶ（説明も出る）。置ける穴が金色に光る |
| 選んだまま空いている穴をタップ | 設置。選んだままなので、続けて別の穴をタップすれば同じトラップを置ける |
| 選んでいるカードをもう一度タップ | 選ぶのをやめる |
| 設置済みの穴をダブルタップ | 撤去・移動（設置コストの半分を消費） |
| 作業員 /「＋作業員」をタップ | 作業員を追加 |
| 天才ボタンからドラッグ | 妨害欄の妨害へ＝解決 / 作業員へ＝再開・加速 / トラップ（穴かカード）へ＝強化・再発明 |
| 妨害欄の札をタップ | その妨害の説明 |
| 塔をスワイプ | カメラ移動（坂道に沿って回転しながら上下）。頂上への追従は「▲頂上へ」ボタンで戻す |
| 俯瞰ボタン | 塔全体を表示（時間がスローになる） |
| ≡ | 一時停止メニュー（音量・ロード・最初から） |

## トラップの発動ルール

| 系統 | 発動間隔 | 狙い |
|---|---|---|
| ダメージ | 0.1秒 | 範囲内で一番頂上に近い敵1体 |
| 遅延 | なし（常に） | 範囲内の全員 |
| 状態異常 | 0.5秒 | 範囲内で一番頂上に近い敵1体 |
| 強制移動 | 1秒 | 範囲内で一番頂上に近い敵1体 |

1回に狙う数は `TRAP_TARGETS`、間隔は `TRAP_INTERVAL`（どちらも `src/config/traps.ts`）で変えられる。
敵が多いほどさばききれずに抜けてくるので、敵の量がそのまま難しさになる。

## セーブ＆ロード

- 10階ごとに自動でセーブ（ブラウザに保存）。階ごとに1つずつ残る
- ロードはメニューかゲームオーバー画面から
  - **続きから**: セーブした時点をそのまま復元
  - **設備リセット**: 高さ・作業員・天才・技術促進はそのまま。トラップを全てポイントに戻し、その階相当の敵が坂道に並んだ状態から建て直す。続いていた神の妨害は消えるが、消えた数だけ1階ごとに追加の妨害が起きる
- ある階でセーブすると、それ以上の階の古いセーブは消える（遊び直した方の歴史が残る）

## 数値・見た目の調整場所

すべてのファイルに日本語で説明コメントを付けています。調整でよく触るのは次のファイルです。

| ファイル | 内容 |
|---|---|
| `src/config/balance.ts` | 建設速度、作業員、ポイント、敵の出現間隔、階数による強化、遅延の減衰、状態異常・強制移動の学習、空中投下、セーブ（間隔・設備リセット） |
| `src/config/enemies.ts` | 敵の種類（体力・速度・攻撃・報酬・出現階） |
| `src/config/traps.ts` | トラップの種類（コスト・範囲・ダメージ・発明階）とシナジー |
| `src/config/god.ts` | 神の妨害（頻度・種類の比率・持続時間・雷の数）と天才（間隔・効果） |
| `src/config/visual.ts` | 塔の大きさ・色、カメラ、アニメーション、操作感 |
| `src/ui/theme.ts` | UIの色・フォント |
| `src/audio/Sfx.ts` | 効果音（仮の電子音） |
| `src/audio/Bgm.ts` | BGM（自動生成。テンポ・音階・コード進行・各パートの音量） |
| `src/render/textures.ts` | 仮素材の絵（本番の画像への差し替え方法も記載） |
| `public/manifest.webmanifest` | アプリ名・アイコン・画面の向き（PWA） |

## フォルダ構成

```
src/
  config/   … 調整用の数値（ここだけ触れば大体のバランスが変わる）
  sim/      … ゲームロジック（描画に依存しない。テストあり）
  render/   … 塔・敵・トラップの描画（擬似3D）
  ui/       … 上下のバー、トラップ一覧、メニューなど
  scenes/   … Phaser のシーン（GameScene がすべてをつなぐ）
  audio/    … 効果音
  i18n/     … 画面の文字列（言語混乱の妨害で差し替える予定）
```
